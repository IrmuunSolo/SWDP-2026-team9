## 5. Нийтлэг дүрэм

1. Ээлж эхлэхдээ: `git switch main` → `git pull --ff-only origin main` → `npm ci` → өөрийн branch үүсгэх.
2. Branch-ийн нэр: `lab<дугаар>/<нэр>-<ажил>`, жишээ нь `lab10/narmandakh-k8s-infra`.
3. Нотолгоог `labs/lab<дугаар>/` дотор `.txt`, `.json`, `.png` хэлбэрээр хадгална (`.log` нь `.gitignore`-д байгаа).
4. Тайлан: `labs/docx/Lab<дугаар>_report_team9.md`. Эхний ээлжийн хүн загвар үүсгэж, бусад нь өөрийн хэсгийг нэмнэ.
5. `.env`, token, нууц үг, хувийн мэдээлэл commit хийхгүй.
6. Хийгээгүй ажлыг хийсэн гэж бичихгүй. Ажиллуулаагүй шалгалтын шалтгааныг тэмдэглэнэ.
7. Командыг өөрийн OS-д тааруулна: Windows PowerShell дээр `npm.cmd`, `npx.cmd`; macOS, Linux дээр `npm`, `npx`.
