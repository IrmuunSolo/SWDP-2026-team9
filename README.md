## Төслийн зорилго

Их сургуулийн орчинд гээгдсэн эд зүйлсийн мэдээллийг Facebook зэрэг олон нийтийн сувгаар хайх шаардлагагүй болгож, төвлөрсөн, хайлт хийх боломжтой систем бий болгох.

CampusFind нь:

* гээгдсэн эд зүйлийг бүртгэх;
* олдсон эд зүйлийг бүртгэх;
* эд зүйлсийг хайх, шүүх;
* эзэмшигч болон олсон хүнийг холбох;
* хувийн чатаар мэдээлэл солилцож эзэмшлийг баталгаажуулах;
* эд зүйл хүлээлгэн өгсний дараа хоёр талаас баталгаажуулах

боломжийг олгоно.

## Үндсэн боломжууд

* Хэрэглэгч бүртгүүлэх, нэвтрэх
* Гээгдсэн эд зүйл бүртгэх
* Олдсон эд зүйл бүртгэх
* Эд зүйлийн зураг нэмэх
* Түлхүүр үг болон шүүлтүүрээр хайх
* Нийтийн сэтгэгдэл үлдээх
* Хувийн чат ашиглах
* Нууц асуултаар эзэмшигчийг баталгаажуулах
* Эд зүйл хүлээлгэн өгсөн эсэхийг баталгаажуулах
* Мэдэгдэл хүлээн авах
* Зөрчилтэй пост болон хэрэглэгчийг зохицуулах

      ↓

## Хөгжүүлэлтийн аргачлал

Төслийг **Scrum** аргачлалын дагуу хөгжүүлнэ.

Product Backlog-д хэрэглэгчийн хэрэгцээг User Story хэлбэрээр тодорхойлж, тэдгээрийг Priority болон Story Point-оор үнэлсэн.

Одоогийн Product Backlog:

* **15 User Story**
* **70 Story Point**
* **8 үндсэн функц (Epic)**

User Story бүр Acceptance Criteria-тэй бөгөөд хөгжүүлэлт дууссан эсэхийг уг шалгуураар тодорхойлно.
